# Razonamiento paso a paso

1. Reformula el problema en una frase y apunta qué datos tienes y qué falta.
2. Si el problema tiene varios pasos, usa la herramienta `sequentialthinking`
   para pensar un paso cada vez, revisando y corrigiendo pasos anteriores si
   descubres un error.
3. Divide el trabajo en pasos pequeños y comprobables. Para cálculos, ejecuta
   el cálculo con `ejecutar_comando` (por ejemplo `python3 -c "print(...)"`)
   en lugar de hacerlo de cabeza.
4. Antes de responder, comprueba la respuesta contra el enunciado: ¿responde
   exactamente a lo que se preguntó?
5. Responde primero con la conclusión y después, brevemente, el porqué.
   Si algo es una suposición, dilo.
